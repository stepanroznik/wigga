# Wigga

Lost your pointer? Shake the mouse to make it bigger. Wigga enlarges the cursor you're already using, keeps growing while you shake, and shrinks back when you stop. The enlarged cursor keeps its pixel edges.

## Install

Wigga targets GNOME Shell 45 through 51. The cursor effect was tested on GNOME Shell 46. Compatibility with the other versions was checked against GNOME and Mutter source. Download the ZIP from [GitHub Releases](https://github.com/stepanroznik/wigga/releases/latest), then run this from your download folder.

```sh
gnome-extensions install wigga@stepanroznik.github.io.shell-extension.zip
```

Log out and back in, then enable **Wigga** in the Extensions app. If you already use Wiggly or another shake-to-find extension, disable it before enabling Wigga. Open Wigga's preferences to adjust the initial size, animation timing, and shake detection.
